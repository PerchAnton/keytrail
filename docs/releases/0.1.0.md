# KeyTrail 0.1.0

The first non-prerelease preserves beta.2 runtime behavior, exports, schema 1 and
ruleset 0.4.0; only package-version metadata changes. No contract migration is
required. See the [0.1.x compatibility and support policy](../stability.md).

## Qualified source

Frozen input commit `85cee8c7cc2180e90ac553cfcfc839d049c56601` completed:

- 47 unit and 30 verification-script tests, types and build.
- Ten full rounds × 180 checks and a separate 180-check four-worker comparison.
- Zero retries/skips, matching semantics and 1,771 distinct journey IDs.
- Maximum successful observation interval 51.6 ms, below the unchanged 100 ms bound.
- 52 CI guard controls and 108 equivalent-work benchmark checks; all three fixtures meet the 20% bound.

[Raw-report checksums and validation](../evidence/reliability-validation-85cee8c.json) ·

the repository's schema/signature validator; it is not an independent audit.

The exact release archive passed `node scripts/check-package.mjs --release`:
ESM/CJS and TypeScript exports, six vanilla examples, three guarded journeys, and
a fresh React portal consumer with its deliberate failure/report check. The
GitHub release assets contain the exact archive, checksum and consumer receipt.
A development package check cannot replace this gate.

## Installation and migration

**Published on npm under `latest` on 8 November 2026.** The registry archive is
byte-for-byte identical to the qualified [GitHub release archive](https://github.com/PerchAnton/keytrail/releases/tag/v0.1.0).
[The npm receipt](../evidence/npm-0.1.0.json) records SHA-256/SHA-512 integrity,
preserved beta tag and clean registry installations in vanilla and React consumers.
ESM/CJS, TypeScript, keyboard journeys, CI guard and the deliberate failure with
HTML/JUnit reports passed on Node 24 and Playwright 1.64.1.

```sh
npm install --save-dev --save-exact keytrail@0.1.0 @playwright/test@1.64.1
```

The original `package-verification.json` remains a pre-publication qualification
record; its `published: false` field is historical. The release also includes the
separate `npm-verification.json`. The tag and original release assets are unchanged.

To upgrade, update an existing beta.2 pin to `keytrail@0.1.0`, refresh
the lockfile and run your application's keyboard tests. Preserve old reports with
their original packageVersion. The npm `beta` tag remains at `0.1.0-beta.2`; `latest` selects `0.1.0`.
No downstream application dependency is updated by this release.
