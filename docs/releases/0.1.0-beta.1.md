# KeyTrail 0.1.0-beta.1

This beta is intended for trials in existing Playwright projects. Its three
assertions cover keyboard focus in custom ARIA dialogs, tab activation and
recovery from invalid form submissions. A failed journey reports the first
mismatch and the dependent checks it prevented. Try one representative journey
and compare the reported focus with what you see when using the keyboard.

Use Node.js 24, Playwright Test 1.64.1 and Chromium. The public API, report schema
v1 and ruleset 0.4.0 carry over from the alpha. Attach the beta package version
when reporting a mismatch. The [examples](../../examples) demonstrate the contracts.

## Qualification of the first beta

On source `f775b30`, all 100 rounds of 172 tests passed on one worker, followed by
172 matching tests on four workers. Independent validation confirmed all 101 raw
reports and 16,261 distinct journey IDs. The 100 ms gap limit applied throughout
and each test had one attempt. [Final reliability evidence](../evidence/reliability-validation-f775b30.json).

All 52 guard cases produced their expected exit codes. The full benchmark passed
108 tests on the recorded Mac, including 30 measured pairs per workload after
five warmups. [Guard results](../evidence/ci-guard.json) and [benchmark results](../evidence/benchmark-validation.json).

The npm prerelease channel is `beta`. The release assets pair the tested tarball
with its SHA-256 checksum and the results from both clean package consumers.
