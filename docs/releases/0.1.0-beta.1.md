# KeyTrail 0.1.0-beta.1 candidate

This candidate is ready for trials in existing Playwright projects. Its three
assertions cover keyboard focus in custom ARIA dialogs, tab activation and
recovery from invalid form submissions. A failed journey reports the first
mismatch and the dependent checks it prevented. Try one representative journey
and compare the reported focus with what you see when using the keyboard.

Use Node.js 24, Playwright Test 1.64.1 and Chromium. The public API, report schema
v1 and ruleset 0.4.0 carry over from the alpha. Attach the beta package version
when reporting a mismatch. The [examples](../../examples) demonstrate the contracts.

## Qualification before publication

The frozen `0.1.0-alpha.6` candidate completed 100 rounds of 172 tests,
followed by 172 matching four-worker checks with a 100 ms observation-gap limit
and zero retries. Its [validation record](../evidence/reliability-validation-1187fde.json)
identifies the original source and environment.

For this beta, collect the guard, benchmark and final reliability records against
its own inputs. Preserve and validate the raw reports before updating the saved
evidence. Run `node scripts/check-release-readiness.mjs` and then
`node scripts/check-package.mjs --release`. Keep the verified tarball, checksum and
consumer reports together. The intended npm dist-tag is `beta` and the GitHub
prerelease tag is `v0.1.0-beta.1`.
