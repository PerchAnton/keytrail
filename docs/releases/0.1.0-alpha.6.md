# KeyTrail 0.1.0-alpha.6 — draft first-release notes

**Prepared, not published.** KeyTrail checks declared keyboard journeys in
Playwright: custom ARIA dialogs, automatic/manual tabs and form-error recovery.

- Guard the dialog opener's actual focus immediately before activation. A mismatch
  fails D01 without pressing Enter/Space and preserves the observed target.
- Require initial/final observations for manual-tabs negative windows, record
  real intervals and block gaps above 100 ms with `OBSERVATION_GAP`.
- Add `inputMode: 'type'` for printable ASCII keyboard events. Preserve the Unicode
  `insertText` default, report the selected mode, and omit values/characters from
  KeyTrail's JSON. Stop further typing if focus or editability changes.
- Extend CI guard validation to reject unsupported passing observation windows.
- Retain ESM/CJS exports, TypeScript declarations, standard Playwright attachments,
  HTML/JUnit integration, vanilla examples and the React StrictMode portal example.
- See the [audit cases](../release-audit.md), [verification record](../verification.md)
  and updated [measured overhead](../performance.md) for the tested scope.

Ruleset 0.4.0, schema 1. Alpha report additions require a matching schema and guard.
Compatibility is not stable. Chromium, Node 24 and the pinned Playwright version
are the supported environment. Passing does not establish WCAG conformance,
screen-reader behavior or complete accessibility. A small native test may be clearer
when a reusable contract provides no benefit.

Use the local tarball instructions until publication is verified. Complete the
[release checklist](../release-checklist.md) before publishing.
