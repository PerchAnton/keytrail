**Draft: final acceptance deferred.** Development uses four rounds and independent package-consumer checks. The historical 100-round counts refer to `0300552` and cannot certify the changed release candidate. Fresh benchmark evidence is recorded separately.

**Prepared, not published.** KeyTrail checks declared keyboard journeys in
Playwright: custom ARIA dialogs, automatic/manual tabs and form-error recovery.

- Guard the dialog opener's actual focus immediately before activation. A mismatch
  fails D01 without pressing Enter/Space and preserves the observed target.
- Require initial/final observations for manual-tabs negative windows, record
  real intervals and block gaps above 100 ms with `OBSERVATION_GAP`.
- Resolve fresh locators into a private browser store and compile the state reader
  once per journey. Read state in the final locator registration, without an extra
  host request. Keep complete cleanup and the 100 ms gap bound.
- Add `inputMode: 'type'` for printable ASCII keyboard events. Preserve the Unicode
  `insertText` default, report the selected mode, and omit values/characters from
  KeyTrail's JSON. Stop further typing if focus or editability changes.
- Reject incomplete CI-guard source maps and conflicting recording hashes in the
  release-evidence check; four regression tests cover the failure paths.
- Extend CI guard validation to reject unsupported passing observation windows.
- Retain ESM/CJS exports, TypeScript declarations, standard Playwright attachments,
  HTML/JUnit integration, vanilla examples and the React StrictMode portal example.
- See the [audit cases](../release-audit.md), [verification record](../verification.md)
  and [measured overhead](../performance.md) for the tested scope.

Fresh measurements on main `f9c492b` completed on 31 October 2026: **108/108**
benchmark tests, zero retries, five warmups and 30 alternating measured pairs per
workload. Median paired overhead is **-9.2%** for dialogs, **-6.8%** for manual
tabs and **-12.6%** for form errors using `insertText`. Both calculations meet the
20% target. These measurements cover synthetic fixtures on one recorded Mac;
the negative results are not a general speed claim. Raw pairs, p95 values
and source hashes are in the [performance report](../performance.md).
