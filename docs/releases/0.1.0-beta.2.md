# KeyTrail 0.1.0-beta.2

Manual tab checks now resolve their original targets and roles in a single Playwright request when the group is safe to use. Changing query membership or mutating the DOM triggers a fresh individual read. A gap greater than 100 ms still blocks activation. The strict validator checks the actual browser report, including the new observation regressions.

## Qualification

On source `fd8f58a`, all ten complete single-worker rounds passed 180 tests each. The separate four-worker run passed the same 180 tests with matching semantic results. All eleven reports were read again, covering 1,771 distinct journey IDs, with zero retries, skipped tests or unexpected failures. [Raw report checksums and validation](../evidence/reliability-validation-fd8f58a.json).

All 52 CI guard controls produced their expected exit codes. The benchmark passed 108 tests, including five warmups and 30 measured pairs per workload. [Guard results](../evidence/ci-guard.json) · [Measured performance](../performance.md).
